# Leaderboard

One row per evaluation run (`evaluation/run_eval.py`), oldest first. Each run's full report, including the definition of every metric (its section 0), is in `results/<run>/report.md`.

- Every image is MSU-normalised before it is measured (temporary; changelog 0019).
- **τ**: the match-score threshold giving a 1% false-match rate on clean prints.
- **1 net rescue**: (probes accepted only after repair − probes accepted only before) / probes, in percentage points, 95% CI.
- **2 FMR change**: false-match rate after − before repair at τ, points, 95% CI; **gate** passes when the upper bound is below +0.5.
- **3 ridge fidelity change**: local ridge correlation with the clean print in the damage mask, after − before repair, 95% CI.
- Cost: median seconds per print, peak GPU / RAM, from `experiments/benchmark.py`.
- `data`: the damage and val/test sets (`config.DATA_VERSION`). **Only compare rows with the same data version.** Older rows (restoration R, no normalisation) are in `LEADERBOARD_eval1.md`.
